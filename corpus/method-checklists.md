# 五步核验清单（可直接照做）

## 第 1 步：注册资本穿透
- [ ] 查 gsxt.gov.cn（被 Cloudflare 挡时改省级政府公告页）
- [ ] 记录注册资本 + 最近变更（减资/增资/时间）
- [ ] 判读：减资 = 收缩警报

## 第 2 步：招聘曲线
- [ ] 主流招聘平台搜公司名
- [ ] 记录当前岗位数 + 历史对比
- [ ] 判读：骤降（>50%）+ 人设不符 = 风险

## 第 3 步：分公司/关联核验
- [ ] 工商数据查分公司注册地
- [ ] 对比对外宣传区号/地址
- [ ] 判读：冒用外省区号 = 门面穿帮

## 第 4 步：关联方风险
- [ ] 股权穿透（股东 → 关联公司）
- [ ] 查关联方经营异常/被执行记录
- [ ] 判读：异常关联需纳入尽调

## 第 5 步：证据链留档（最重要）
- [ ] 每条结论存原始公开文件（截图/链接/公告页）
- [ ] 字段不改一字
- [ ] 输出："证据证明"式报告，非"我信任"式建议
